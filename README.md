### Основные свойства Flexbox, использованные в работе:

>`display: flex` — превращает элемент в флекс‑контейнер.

>`flex-wrap`: wrap — разрешает перенос дочерних элементов на новую строку.

>`justify-content` — выравнивает элементы по главной оси.

>`align-items` — выравнивает элементы по поперечной оси.

>`flex: 1 1 250px` — задаёт гибкость, сжатие и минимальную ширину элемента.

>`align-self` — переопределяет выравнивание для отдельного элемента.

>`gap` — задаёт отступы между элементами в сетке.
