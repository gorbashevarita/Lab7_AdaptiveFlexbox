# Лабораторная работа №7 по ИСРПО
## *Тема:Адаптивная верстка: Flexbox*
##### **Цель работы:** освоить современные технологии CSS-разметки — Flexbox

##### Структура проекта:
- папка **img**
- файл **README.md**
- файлы css:
  - **flexbox.css**
  - **styles.css**
- файлы html:
  - **flexbox.html**

#### Задачи:
- Создать HTML‑структуру с несколькими разделами (меню, карточки, сетка).

- Разработать CSS‑стили для:

  - сброса стандартных отступов;

  - базового оформления документа;

  - навигационного меню;

  - карточек товаров;

  - центрирования элементов;

 - адаптивной сетки из 100 элементов.

- Обеспечить адаптивность макета при изменении ширины экрана.
